# Ridgefield High Mock Markets (Fake Money Only)

A simple Kalshi-style classroom demo app where students can:

- Create accounts with a **custom starting fake balance**.
- Create YES/NO prediction markets (“bets”).
- Place fake-money trades on YES or NO outcomes.
- View balances and an activity ledger.

## Important

This is **not** a real betting platform.

- No real money
- No payouts
- Educational/demo use only

## Run locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.
